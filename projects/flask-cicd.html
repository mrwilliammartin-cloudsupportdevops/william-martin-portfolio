Flask CI/CD on Kubernetes

A practical deployment pipeline that moves a Flask application from source code to a running Kubernetes service.

Technology: Docker, Kubernetes, Git, Azure DevOps, Flask

PROJECT DETAILS

What I built and learned.

The application was containerised with Docker and tested locally before being pushed to a container registry. Kubernetes resources were then used to deploy the image and expose the application through a service. Key learning outcomes included image building and tagging, registry authentication, Kubernetes namespaces, deployments, pods, services and troubleshooting application availability. Next improvement: automate the complete build, test, push and deployment process through a CI/CD pipeline with environment-specific configuration.

What this demonstrates

Problem solving · Technical troubleshooting · Documentation · Practical implementation · Continuous learning
