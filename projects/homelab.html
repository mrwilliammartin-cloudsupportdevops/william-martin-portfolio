01 — PURPOSE

Turning learning into a repeatable infrastructure environment.

NEXUS-CORE is my personal lab environment for turning Cloud Support and DevOps concepts into practical, repeatable work. Instead of treating each exercise as an isolated tutorial, I use the lab to practise administration, networking, automation, containerisation, troubleshooting and documentation.

The environment is deliberately treated like a small operational platform: changes are tested, problems are investigated systematically, and working configurations are documented so they can be reproduced later.

Current focus

  • Linux — services, permissions, networking and CLI administration
  • Networking — LAN discovery, routing, SSH and remote administration
  • Containers — Docker images, containers and application deployment
  • Kubernetes — deployments, services and workload troubleshooting
  • DevOps — Git, CI/CD, automation and infrastructure practices

02 — CURRENT WORK

Projects already built in the lab.

Linux Network Scanner

Nmap + Bash + PHP + Apache dashboard for controlled network discovery, service exposure review, scan history and scanner health.

Flask CI/CD

Containerised Flask application published to Docker Hub and deployed to a local Kubernetes environment with a NodePort service.

Remote Administration

Hands-on use of SSH, RDP and Tailscale concepts to manage lab systems and troubleshoot connectivity across different networks.

Automation

Bash and Python exercises focused on repeatability, data collection, troubleshooting and operational workflows.

03 — ROADMAP

Building toward a dedicated Home Lab platform.

Next phase

  • Move the working lab workloads from the Windows development environment to the physical NEXUS-CORE server.
  • Evaluate Proxmox VE as the dedicated virtualisation platform.
  • Re-establish the Ubuntu and security-testing workloads as managed lab VMs.
  • Implement reliable remote administration and backup procedures.

Project status

The dedicated physical-server migration is intentionally marked as in progress. The existing lab workloads remain preserved until the physical NEXUS-CORE platform is available for the migration and verification phase.

04 — WHAT THIS DEMONSTRATES

Practical infrastructure thinking.

NEXUS-CORE demonstrates a learning approach based on building, breaking, troubleshooting, documenting and improving systems — the same cycle used when supporting real infrastructure.
